# 内录工作台 · SoundCapture

Windows 上录制**电脑内部声音**（WASAPI 回环）和麦克风，并把录下来的文件管起来的一体化小工具。
录课、录会议、录游戏原声、边放边讲解配音，都能用；数字直取，不经过空气，所以没有环境噪音。

- 平台：Windows 10 / 11（依赖 WASAPI，其它系统跑不了）
- 界面：Tkinter，深色，高 DPI 自适应
- 依赖：只用到 Python 标准库 + `PyAudioWPatch`；`ffmpeg` 可选（有它才有 MP3 / 多轨混音 / 工具页功能）
- 不写注册表、不改系统设置、不联网，所有产物都放在本目录的 `录音输出/`

当前版本：**v1.0.0**（2026-10-21）

---

## 一、能做什么

### 录制页
- **三种录制模式**：仅内部声音 / 仅麦克风 / 内部 + 麦克风同时录
- **实时电平表**：逐通道显示输入强度，削波（爆音）会闪红并计数
- **监听电平**：只出电平不写文件，先确认设备有没有声音再正式开录
- **暂停 / 继续**：暂停期间的声音不进文件、也不计时，接完电话接着录，成片连续无空档
- **定时停止**：到点自动结束并保存
- **悬浮条**：最小化后收成一条始终置顶的小窗口，状态 / 计时 / 迷你电平 / 开始·暂停·停止全在上面

### 录音库页
- 列出所有录音并标注「这个文件是什么」；双击播放，可多选后去工具页批量处理
- 重命名 / 删除 / 打开所在文件夹

### 工具页
- 格式转换（mp3 / wav / flac / m4a / ogg …）
- 片段裁剪 + 淡入淡出
- 响度归一化（-16 LUFS）
- 多文件按序拼接
- 查看音频信息（时长、电平、流信息）

## 二、三种模式分别输出什么文件

| 模式 | 输出 | 说明 |
|---|---|---|
| ① 仅内部声音 | `录音_时间_内部声音.wav`<br>`录音_时间_内部声音.mp3` | WAV 是无损母版，做后期用它；MP3 是同一段内容的压缩副本，方便发出去 |
| ② 仅麦克风 | `录音_时间_麦克风.wav`<br>`录音_时间_麦克风.mp3` | 麦克风保持原始采样率（常见 16 kHz）不重采样，母版干净 |
| ③ 内部 + 麦克风 | `录音_时间_内部声音.wav`<br>`录音_时间_麦克风.wav`<br>`录音_时间_内部加麦克风.wav`<br>`录音_时间_内部加麦克风.mp3` | 前两个是**独立分轨**（各录各的，可单独调音量 / 降噪），第三个是把两轨对齐后的**合成成品**，直接听这一版 |

WAV 和 MP3 不是两段不同的录音，是同一次录音的两种格式。
不想要 MP3 副本，取消勾选「录制选项 → 生成 MP3 副本」，每次就只输出 WAV（模式③ 仍会保留 3 个 WAV：两条分轨 + 一条成品）。

## 三、快速开始

### 方式 A：直接用现成的 exe（推荐）

1. 到本仓库 Releases 下载 `SoundCapture-v1.0.0-win64.zip`
2. 解压到任意文件夹（不要解压到中文路径以外的奇怪位置，普通路径即可）
3. 双击 `SoundCapture.exe`

需要 MP3 / 混音 / 工具页功能的话，本机还要有 `ffmpeg`（见下一节）。

### 方式 B：从源码运行

```bat
pip install -r requirements.txt
python SoundCapture.py
```

或双击 `启动.bat`（它会优先找已经打好的 exe，没有才用 Python 跑源码；
换机器时请把里面的 `PY=` 一行改成你自己的 `pythonw.exe` 路径）。

## 四、环境要求

| 项目 | 要求 | 备注 |
|---|---|---|
| 系统 | Windows 10 / 11 | WASAPI 回环是 Windows 的能力 |
| Python（仅源码运行需要） | 3.9 ~ 3.12，实测 3.11 | 官方安装器要勾上 **tcl/tk and IDLE**，否则没有 `tkinter` |
| PyAudioWPatch | 0.2.12.8 | 带 WASAPI 回环支持的 PortAudio 分支 |
| ffmpeg | 可选 | 没有它：录音存 WAV 照常，但 MP3 副本、模式③的合成成品、工具页全部功能不可用 |

### ffmpeg 是怎么找的

程序顶部 `FFMPEG` 常量（第 90 行附近）先试一个固定路径，不存在就退回调用 PATH 里的 `ffmpeg`。
所以换机器时二选一：

- 装好 ffmpeg 并加进系统 PATH（最简单，推荐）
- 或把 `ffmpeg.exe` 放到软件目录，然后把那一行改成你自己的路径

想把 ffmpeg 一起塞进发布包：把 `ffmpeg.exe` 复制到 `dist\SoundCapture\` 下，
并把常量改成按 exe 自身位置定位，例如
`FFMPEG = str(Path(sys.executable).with_name("ffmpeg.exe"))`。
（注意这会随包多带约 70 MB。）

## 五、界面速览

```
录制页   录制模式 / 设备选择 / 电平表 / 计时 / 开始·暂停·停止 / 本次输出的文件
录音库页 文件列表 + 「这个文件是什么」标注 / 播放 / 重命名 / 删除 / 打开文件夹
工具页   格式转换 / 裁剪+淡入淡出 / 响度归一化 / 拼接 / 音频信息
悬浮条   ● 状态 · 计时 · 迷你电平 · ▶开始(‖暂停/▶继续) · ■停止 · ⤢展开主窗口
```

录制过程中点标题栏的「—」最小化，窗口会自动收成悬浮条而不是缩进任务栏；
悬浮条上的主按键会随状态变脸：待机是「▶ 开始」，录制中变「‖ 暂停」，暂停后变「▶ 继续」。

完整操作细节见 [`使用说明.txt`](使用说明.txt)。

## 六、目录结构

```
内录工作台/
├─ SoundCapture.py        主程序（单文件，界面 + 录制 + 工具全在里面）
├─ SoundCapture.spec      PyInstaller 打包配置
├─ 启动.bat               双击启动（优先 exe，其次 Python 源码）
├─ 使用说明.txt            面向使用者的操作说明
├─ BUILD.md               打包说明（环境、命令、自检、ffmpeg）
├─ 发布步骤.md             从本地到 GitHub Release 的逐步操作清单
├─ 首次提交.bat            交互式：填用户名/邮箱/仓库名 → 提交并打 tag
├─ requirements.txt       源码运行所需依赖
├─ requirements-build.txt 打包所需依赖
```

第一次发布：照着 [`发布步骤.md`](发布步骤.md) 做就行，不用自己拼 git 命令。

打包后产物在 `dist/SoundCapture/`（onedir 模式，约 26 MB，压缩后约 11 MB），
整目录压缩后即可分发；`dist/` 和 `build/` 都不进仓库。

## 八、常见问题

**录内部声音一点声音都没有？**
先确认电脑当时确实在播放声音；就算全程静音，程序也会留下等长的静音文件（这是正常的）。
模式① 的设备下拉里，条目的前缀是「系统内部声音」，其中带 **★当前播放设备** 的那一项
就是正在出声的那个，一般选它即可（程序也默认帮你选中它）。

**某个耳机 / 蓝牙设备打不开？**
点「刷新设备列表」；仍不行就在对应下拉里换一个设备。
打开超过 15 秒无响应的设备会被记进 `_设备黑名单.json`，下次自动跳过（删掉这个文件即可恢复）。

**高分屏上字被挤爆 / 窗口超出屏幕？**
程序按系统缩放系数自动换算布局像素，一般无需处理；窗口超出屏幕拖动边缘缩小即可。

**杀毒软件报毒？**
PyInstaller 打包的 exe 是常见误报来源（尤其 onedir + UPX）。
Release 里同时提供源码，可自行对照打包；也可以在项目设置里关掉 UPX 重新打一版。
